# 💰 Personal-Expense-Tracker

### A Modern Personal Expense Tracker Built with C++ & Qt/QML

Personal-Expense-Tracker is a modern desktop-based personal finance application developed using **C++ and Qt/QML**.

It allows users to record expenses, manage their monthly budget, monitor remaining funds, and analyze their spending through a clean and attractive graphical interface.

---

## 🚀 HOW TO ACCESS THE APPLICATION

⚠️ **IMPORTANT:**  
The application is provided as a ZIP file.

Download and extract the ZIP before running the application.

⚠️ **DO NOT TRY TO OPEN THE EXE DIRECTLY FROM GITHUB**

GitHub does not run Windows `.exe` applications directly.

---

## 1️⃣ DOWNLOAD THE APPLICATION

Go to the **Releases** section of this repository and download:

PersonalExpenseTracker.exe

2️⃣ EXTRACT THE ZIP
After downloading:

Right-click the ZIP → Extract All → Extract

Open the extracted folder.

Do not run the .exe directly from inside the ZIP.

3️⃣ RUN THE PersonalExpenseTracker GUI
Inside the extracted folder, find the PersonalExpenseTracke.exe file.

For example:

PersonalExpenseTracke.exe

Double-click the .exe file to launch the application.

4️⃣ ⚠️ WINDOWS SECURITY WARNING
Windows may display "Windows protected your PC" when you open the application.

If this appears:

Click More info → then click Run anyway

The application will then open normally.
